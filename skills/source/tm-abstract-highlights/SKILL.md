# TM Abstract Highlights

Use this skill to produce concise, journal-ready abstracts and highlights for Tourism Management-style empirical papers.

## Required Inputs

Work from the user's provided manuscript text, model card, results, and section logic. If core results are missing, ask for them or mark the relevant result as needing confirmation. Do not invent data, citations, sites, sample sizes, or supported hypotheses.

Extract or confirm:
- Theory lens
- X antecedents, M mediators, Y outcomes, W moderators or boundary conditions
- Study context and sample/data source
- Supported and unsupported direct, mediation, and moderation results
- Main theoretical contribution

## Abstract Workflow

1. Build the abstract as a single chain:
   - Problem hook
   - Research gap
   - Theory and model
   - Data/context
   - Main findings
   - Contribution

2. For Tourism Management, keep the abstract at or below 150 words unless the user asks otherwise.

3. Prefer this order:
   - Sentence 1: concrete problem in the research context.
   - Sentence 2: specific research gap, not a variable list.
   - Sentence 3: theory, constructs, mechanism, and boundary condition.
   - Sentence 4-6: data and results.
   - Final sentence: theoretical contribution in plain language.

4. Avoid repeating concept explanations. If a culturally specific construct appears, define it briefly inside the model sentence, for example:
   - `place-based everyday vitality (Yanhuo Chi)`
   - `people-based interpersonal warmth`

5. Keep terms consistent with the manuscript. Do not rename constructs casually.

6. Use direct verbs:
   - `examines`
   - `tests`
   - `shows`
   - `positively affects`
   - `partially mediates`
   - `moderates`
   - `extends`

7. Avoid weak or inflated abstract phrasing:
   - `significantly influence` when simple `positively affect` is enough
   - `novel`, `nuanced`, `theoretical tension`, `unique lens`, `important implications`
   - vague contribution endings that do not state what was extended or clarified

## TM Abstract Quality Checks

Before finalizing, check:
- The first two sentences connect naturally.
- The research gap follows from the problem hook.
- The abstract does not sound like an introduction paragraph.
- Each construct appears with the same role used in the paper.
- The mediator is not described as both mechanism and outcome in the same clause.
- Moderation is stated only for supported paths unless the user asks for a planned model.
- No unsupported causal claim is added.
- No citation is included unless the user explicitly asks for cited abstract text.
- Word count is reported when the user asks for TM compliance or compression.

## Highlights Workflow

Write 3-5 highlights unless the user asks for a different number. Each highlight should be one concise sentence or phrase, normally under 85 characters if possible.

Strong highlights should state what the paper does or finds:
- Extends theory to a specific context.
- Quantifies or validates a construct.
- Distinguishes related constructs.
- Identifies a mechanism.
- Identifies a boundary condition.

Prefer:
- `Extends intergroup contact theory to everyday encounters in lived heritage settings.`
- `Quantifies Yanhuo Chi as place-based vitality distinct from interpersonal warmth.`
- `Shows how flow-like involvement links everyday contact cues to prosocial behavior.`
- `Identifies tourist origin as a boundary condition for the Yanhuo Chi pathway.`

Avoid:
- Repeating the title.
- Generic claims such as `This study has theoretical and practical implications.`
- Unsupported novelty claims.
- Incorrect phrasing such as `internal tourists' prosocial behaviors`.

## Revision Output

When revising an existing abstract or highlights:
1. Briefly diagnose the main issue.
2. Give the revised version.
3. Report word count for abstracts when relevant.
4. If asked, bold key changes relative to the user's version.

Keep explanation short unless the user asks for detailed TM editor analysis.
