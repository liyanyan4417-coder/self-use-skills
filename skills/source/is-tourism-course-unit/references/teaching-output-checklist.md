# Teaching Output Checklist

Create these outputs for a completed unit:

```text
outputs/teaching/{slug}-course.pptx
outputs/teaching/{slug}-lecture-script.md
outputs/teaching/{slug}-lecture-script.docx
outputs/teaching/{slug}-student-handout.md
outputs/teaching/{slug}-comparison.md
outputs/teaching/{slug}-teaching-outline.md
```

## Recommended PPT Structure

1. Title and opening question
2. Why this is not a generic AI question
3. IS paper research question
4. IS theory and mechanism
5. IS evidence
6. IS findings
7. Tourism application bridge
8. Tourism paper research question
9. Tourism theory and mechanism
10. Tourism evidence
11. Tourism findings
12. Management interventions
13. Comparison
14. Integration model
15. Classroom workshop
16. Conclusion and exit ticket

## Lecture Script Structure

For each slide include:

- teacher script
- classroom interaction
- expected student direction or teaching note

## Student Handout Structure

Keep it short:

- paper references with DOI
- what the lesson studies
- IS paper in plain language
- tourism paper in plain language
- comparison model
- management implications
- discussion questions
- blackboard model
